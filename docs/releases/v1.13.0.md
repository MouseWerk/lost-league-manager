Lost League Manager 1.13.0

## Improved

- Valorant: the top bar switches between League and Valorant (with the two game logos). With
  Valorant selected, Play signs the account in and starts Valorant, or switches the account when
  the Riot Client is already open. Each account shows its Valorant rank with the emblem, RR and
  peak, its Valorant Points, Radianite and Kingdom Credits, the four skins of the daily store, the
  Night Market while it runs, and its last games with map, agent, score and result.
- Valorant ranks are read from the Valorant client at sign-in. With a free HenrikDev API key
  (Settings > Riot API key) they also update for accounts that are not signed in. The key is stored
  encrypted like the Riot API key.
- Valorant loadout: see every skin an account owns, and equip a skin, chroma or level on the
  account that is signed in. Save the loadout as a set for an agent; if you switch it on, the set
  is equipped when you lock that agent. Riot does not offer this officially; the app uses
  Valorant's own servers the way the game does.
- Collection: champions, skins and shards of each account are read from the League client at
  sign-in and after each game. Search for a champion or skin and the list shows the accounts that
  own it ("Owns Star Guardian Ahri"); the panel has a Collection block with a list of everything.

## Fixed

- Standard Valorant skins show the weapon instead of a placeholder picture.

## Checklist for Windows (manual)

- Start 1.13.0: What's new lists the changes.
- Click the Valorant logo in the top bar: the rows show Valorant ranks and the panel the Valorant
  block; click the League logo: everything is as before.
- With Valorant selected, Play an account: Valorant starts on that account. Afterwards the panel
  shows rank, wallet, store and last games.
- Open Loadout on the signed-in account, equip another Vandal skin: it is equipped in the game.
  Save the loadout as a set for an agent and equip it again from the list.
- Settings > Riot API key: save a HenrikDev key, then refresh the rank of an account that is not
  signed in.
- Sign in to League, then type a skin you own in the search: the account shows "Owns ...".
