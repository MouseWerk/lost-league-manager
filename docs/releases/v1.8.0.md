Lost League Manager 1.8.0

## Improved

- A new look for the whole app: new type (JetBrains Mono for titles and numbers, Instrument Sans for text) and colors
  taken from the logo, with teal for the main actions. The fonts are built in, so the app looks the
  same without an internet connection.
- Light and dark themes. Choose Light, Dark or System in Settings > Appearance; System follows the
  Windows setting and switches with it.
- Accounts are shown as a list. Pick an account to see its rank and LP, flex rank, rank history,
  last 5 games and notes in the panel beside the list, with Play, Copy login, Copy password,
  OP.GG, Edit, Favourite and Delete in one place.
- Play an account straight from its row with the Play button, or by double-clicking the row. The
  arrow keys move through the list.
- Filter the list by server with one click (All, EUW, NA and so on).
- The top bar holds the navigation and Auto-accept, so they are reachable from every page.
- Settings are grouped into sections (Appearance, Automation, App behavior, League client, Riot API
  key, Vault and backups, Game overlay, About) that you can jump to from the left.
- Discord, the website, the version and What's new are under Settings > About.
- Tools explain in plain words what each fix does.
- An account whose rank could not be looked up says "Rank unavailable", with the reason when you
  point at it.
- Drop-down lists (sort order, server, client language) open in the app's own style in light and
  dark, instead of the plain Windows list. They work with the arrow keys, Home and End, Enter,
  Escape and by typing the first letters.
- Ranks show the ranked emblems from the League client in the account list, the account panel and
  the Live view.
- Add account sits next to search and sort, right above the list.
- Buttons, fields, tabs and chips share one set of heights and corner shapes across all pages.

## Fixed

- Stat viewer: attack speed per level uses each champion's real attack speed ratio, so champions
  like Graves and Zeri show the correct value at higher levels.
- Item gold value now counts ability haste, lethality, armor and magic penetration, omnivamp, heal
  and shield power, tenacity and base regeneration. Items with these stats showed a gold value
  that was too low (Black Cleaver 88% instead of 121%).
- Labels and buttons use one consistent writing style.

## Checklist for Windows (manual)

- Switch Windows between light and dark mode (Settings > Personalization > Colors) with the app
  open and the theme on System: the app switches with it.
- Choose Light, then Dark in Settings > Appearance, restart the app: it starts in the chosen theme.
- Click an account, then another: the panel on the right follows; Play as <name> starts the
  selected account. Double-click a row: that account starts.
- With accounts on two servers, click a server chip: only those accounts stay in the list.
- Drag an account in "Your order" to a new place, restart: the order is kept.
- Lock the vault (Settings > Vault and backups), restart: the lock screen matches the theme.
- Open the sort list, the server list in New account and Client language in Settings: each opens
  below or above the field, matches the theme, and Escape closes only the list, not the form.
- Open the Stat viewer, pick Graves, move the level to 18: attack speed reads 0.725.
- Open Item gold value, pick Black Cleaver: ability haste is listed with a gold value and the
  efficiency is about 121%.
- With a ranked account in the list, the rank shows its emblem next to the tier.
- Set the interface size to 125%: nothing is cut off on the Accounts page and in Settings.
