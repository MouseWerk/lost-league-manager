Lost League Manager 1.7.0

## Improved

- Quick add: when adding an account, paste a Riot ID (Name#TAG) or an OP.GG profile link and press
  Find. Riot ID, region and label fill in, with a preview of icon, level, rank and top champions. A
  pasted OP.GG link searches right away and uses its own region.
- "From League client" in Quick add takes the account that is signed into the running client.
- Editing an account shows the same panel as "Link summoner", for accounts saved without a Riot ID.
- Accounts signed into the League client get their Riot ID and region filled in automatically.
- No Riot API key needed: ranked stats and "Last 5 games" come from OP.GG when no key is set or the
  key has expired. Account cards then show the season's most played champions.
- New regions: ME, VN, TW, SG, PH and TH.
- Safer secrets: the Riot API key is stored encrypted by Windows and is never shown again after
  saving ("Key saved", with Replace and Clear). The vault password is checked with a salted,
  slow hash, and after five wrong tries the lock screen waits before the next try.
- While the vault is locked, the tray menu, jump list and desktop shortcuts no longer log in; they
  open the lock screen.
- Backups ask for a backup password when you export, and only open with it. Older backups still
  import.
- Launching is safer: only one launch runs at a time, Cancel stops it in every step, and after
  logging in the app checks which account is actually signed in. Launching while you are in a game
  asks first, because it closes League.
- Passwords with umlauts and other non-English characters log in correctly.
- The Live view follows the client: queue, champ select and game panels and their timers switch with
  the game phase, and the in-game timer shows.
- Ranked stats refresh after 10 minutes instead of staying until restart, and a failed lookup is
  retried a minute later.
- Sort by rank orders divisions and LP correctly.
- Dialogs work with the keyboard: Escape closes the topmost one, focus moves into the dialog and
  back afterwards, and a delete confirmation starts on Cancel. Confirm buttons say what they do.
- Stat Viewer: the level slider can be dragged and moved with the arrow keys; the item list shows
  only Summoner's Rift items, with gold values from the current patch. Items whose stats can't all be
  priced are marked.
- The window opens right away instead of waiting for champion data to download, and champion and
  item data load again on their own after a failed download.
- Account card buttons sit in two rows instead of leaving Delete alone on a third.
- Calmer look: no glowing frames on the active account, selected items, tabs or focused fields;
  keyboard focus shows one neutral ring. Status dots pulse a few times and then rest, and the app
  honors the Windows "Show animations" setting.
- Checkboxes match the app's dark style.

## Fixed

- Two launches could run at once (for example from the tray during a launch) and type into the
  same Riot Client window.
- Login keystrokes could go to another window whose title contained "Riot Client".
- With "Stay signed in" in the Riot Client, the previous account was logged in while the app said
  the chosen one was ready.
- A failed login with "Minimize app when launching this account" on left the window hidden.
- "Minimize on game start" never minimized the app.
- "Auto random skin" kept changing the skin during champion select and overwrote your own choice.
- When League was closed or crashed, the app kept showing it as running.
- LAN and LAS accounts were looked up on each other's server; OCE and Southeast Asia accounts failed
  with the Riot API key, and the message wrongly blamed the key.
- With League closed after a crash, the app reset your Discord status every few seconds.
- A damaged accounts or settings file was treated as empty and then overwritten. A copy of it is now
  kept next to it and the app says so.
- An account added or edited while the app linked a Riot ID from the client could be undone.
- Install & Restart for an update could leave the app running.
- Dragging an account one place down or to the end of the list did nothing.
- Rank history added entries for unchanged Master and higher ranks.
- The League and Riot Client folders were not found for installs outside C:\Riot Games (for example
  in a Steam library) when the configured path was out of date.
- With "Minimize app when launching this account" on, an unreadable saved password hid the window
  and the error with it.
- A slow or stuck League client could leave stats and buttons waiting with no end.
- Ranked stats show the last known rank with a note when every source fails, instead of nothing.
- Dodge, status message and profile background reported success even when they failed.

## Checklist for Windows (manual)

- Update over an existing install with saved accounts and a Riot API key: accounts still log in,
  Settings shows "Key saved", ranks load.
- Turn on the vault, restart: the lock screen shows; a wrong password five times makes it wait;
  the right password opens the accounts. Right-click the tray icon while locked: no account logs in.
- Export a backup with a backup password, delete one account, import the file: it asks for the
  password and brings the account back.
- Launch account A, then quickly launch it again from the tray: the second launch is refused.
  Press Cancel while it says "Launching Riot Client": nothing is typed afterwards.
- Log in with "Stay signed in" on for account A, then launch account B: the app reports that A is
  signed in instead of saying B is ready.
- Launch an account whose password contains an umlaut (for example "Passwört1"): login works.
- Queue up, accept, go through champ select into a game: the Live view panels and timers follow;
  with "Minimize on game start" on, the app minimizes when the game starts.
- Add an account through Quick add with an OP.GG link (for example
  `https://op.gg/lol/summoners/euw/<Name>-<TAG>`): region switches to the link's region, the card
  shows rank and icon right after Save.
- With League running and signed in, open Add, click "From League client": Riot ID, region and login
  name are filled in.
- Clear the Riot API key in Settings and restart: account cards still show ranks.
- Close League, leave its lockfile in place (or kill the client), watch Discord for a minute: the
  status time keeps counting and does not restart.
- Turn off Windows Settings > Accessibility > Visual effects > Animation effects: no pulsing dots.
- Press Tab through the Accounts view: every focused control shows the gray ring, nothing teal.
- Click "Install & Restart" on an update: the app closes and the new version starts.
